# What changed on 2026-11-13

## How to run the site now
    npm start            # from this folder, then open http://localhost:4173
Do NOT use `python -m http.server`: it has no forms API (every form fails) and it
serves every file in the folder, including server code.

To get lead notifications, copy `.env.example` to `.env` and fill it in.

## 1. Security
- Leads database moved out of the public folder: `data/steven_lenz.db`.
- `site/server.js` now serves an allowlist only (pages, assets, css, js, content,
  areas, articles). Server code, db, scratch, package.json return 404.
- `pitch.html` / `preview.html` are local-only (404 when NODE_ENV=production),
  marked noindex, and removed from sitemap.xml.
- Rate limiter no longer trusts a forgeable header (set TRUST_PROXY=1 behind a
  proxy) and cleans up after itself. Gzip, cache headers, ETags, 404 page added.

## 2. One lead pipeline
- `site/api/lead.js` is the single handler for every form (contact, listing,
  concierge, private exclusives, valuation). It validates, saves to SQLite, then
  queues notifications.
- `site/lib/outbox.js` delivers notifications with retries (email to Steven,
  thank-you to the visitor, AI-desk webhook, Sheets webhook). Status is stored
  in the `outbox` table, so nothing is lost if a provider is down.
- Leads now record form type, campaign (UTM) and referrer, plus `status` and
  `notes` columns ready for the admin panel.

## 3. Honest forms
- `window.SLForms` (top of `site/js/editorial-nav.js`) is the only way forms
  post. "Thank you" appears only after the server confirms the save; otherwise
  the visitor sees a real error with Steven's phone number.
- Lead details are no longer copied into the visitor's browser storage.

## 4. Mobile
- New `site/css/mobile.css`, loaded last on every page. The rules it follows
  are written at the top of the file.
- Home: each scene is copy on top + panel pinned to the bottom, sized so they
  cannot overlap; duplicate CTAs removed; the lead form gets the full screen
  with a sticky submit button and a longer scroll window.
- Inner pages: full-width buttons, 16px inputs, 44px tap targets, compact rows
  for long home lists, styled "View Property" links.

Originals of every edited file are in `_backup_2026-11-13/`.
